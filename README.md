# VI65 for the TK2000 / MPF-II

A vi text editor for the TK2000 and the Microprofessor II (MPF-II): 56 columns, Portuguese
accents, files on tape or on a TKDOS disk.

Um editor de texto vi para o TK2000 e o Microprofessor II (MPF-II): 56 colunas, acentos do
português, arquivos em fita ou em disco TKDOS.
